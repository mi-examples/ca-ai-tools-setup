# Customer Documentation

Produce or update customer-facing documentation for delivered Custom Apps.

```text
$ARGUMENTS
```

Treat the arguments as the scope: a Linear epic key or URL, an app slug, a flow name, or an existing path
under `docs/customer/`.

Read `./.claude/skills/customer-app-docs/SKILL.md` and follow its run order. The person invoking this command
has decided the flow is ready — do not gate on epic state, test-run state or open bugs. Hand back file paths;
do not send or publish the document anywhere.
